Automação de API e Mobile

Testar onde o defeito é mais barato de achar: na API, antes da tela — e no aplicativo, onde o usuário está.

  • 60 horas
  • Nível: intermediário

O que você precisa antes

Exige noção de programação. Não depende do curso de automação web — os dois podem ser feitos em qualquer ordem.

O que você vai aprender

  • HTTP, REST e contrato de API para quem testa
  • Postman e Newman: da coleção manual à execução na esteira
  • REST Assured e Karate: teste de API em código
  • Contrato, esquema e teste de integração entre serviços
  • Automação mobile: Appium, Espresso e Detox
  • Emulador, dispositivo real e nuvem de dispositivos
