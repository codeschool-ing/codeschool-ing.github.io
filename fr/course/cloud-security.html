Sécurité du Cloud

Dans le cloud la faute est partagée, mais la facture est pour vous : comprenez le modèle de responsabilité et où les failles arrivent.

  • 50 heures
  • Niveau: intermédiaire

Ce qu’il vous faut d’abord

Exige le cloud : le modèle de responsabilité partagée suppose que vous sachiez quelle moitié est la vôtre.

Ce que vous allez apprendre

  • Cloud et serveur local : ce qui change pour la sécurité
  • Responsabilité partagée avec le fournisseur
  • Identité et accès : le nouveau périmètre
  • Stockage exposé et mauvaise configuration
  • Sécurité de l’infrastructure as code et du serverless
  • Journalisation, audit et conformité dans le cloud

  • AWS, Google Cloud et Azure : équivalences de services
  • Moindre privilège en pratique : fédération, SSO et le chemin d’élévation que personne n’a révoqué
  • Clés d’accès, secrets et rotation
  • Isolation réseau : points de terminaison privés, contrôle de sortie, et le sous-réseau qui a atteint internet
  • Stockage exposé : compartiments publics et l’erreur la plus courante de la décennie
  • Stockage personnel en entreprise : S3, OneDrive, Dropbox, Box, iCloud et Google Drive

  • Infrastructure as code : secret dans le dépôt et relecture du plan
  • Sécurité du serverless : permissions des fonctions et dépendances
