Automatisation des Réseaux

Cessez de configurer équipement par équipement : décrivez le réseau en code, validez et appliquez à l’échelle.

  • 60 heures
  • Niveau: intermédiaire

Ce qu’il vous faut d’abord

Les deux sont nécessaires.

Ce que vous allez apprendre

  • API réseau : REST, NETCONF, RESTCONF et gNMI
  • Modélisation avec YANG, JSON et XML
  • Automatisation avec Python : Netmiko, NAPALM et Nornir
  • Ansible appliqué aux équipements réseau
  • Gabarits de configuration avec Jinja2
  • Source de vérité, sauvegarde et validation de configuration

Liste complète des sujets

  • Pourquoi automatiser : erreur humaine, échelle et répétabilité
  • API REST sur les équipements réseau : authentification, verbes et pagination
  • NETCONF et RESTCONF : configuration structurée et transactionnelle
  • gNMI et télémétrie en flux
  • Modélisation des données avec YANG
  • Formats : JSON, XML et YAML dans la configuration réseau
  • Webhooks et intégration avec les systèmes de tickets
  • Python pour le réseau : Netmiko, NAPALM, Nornir et Paramiko
  • Ansible pour le réseau : inventaire, modules constructeurs et idempotence
  • Gabarits de configuration avec Jinja2
  • Sauvegarde automatisée et comparaison de configurations (diff)
  • Source de vérité et inventaire avec NetBox
  • Validation et tests avant application en production
  • Intégration continue appliquée au réseau
  • Panorama des réseaux définis par logiciel (SDN) et des contrôleurs
