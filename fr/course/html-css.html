HTML et CSS

Construisez et stylez des pages à partir de zéro, avec une mise en page vraiment responsive.

  • 70 heures
  • Niveau: débutant

Ce qu’il vous faut d’abord

Aucune programmation requise. C’est le premier cours de qui construit pour le web.

Ce que vous allez apprendre

  • HTML sémantique et structure des documents
  • Sélecteurs, cascade, spécificité et variables CSS
  • Mise en page avec Flexbox et Grid
  • Responsive, media queries et mobile first
  • Frameworks CSS : Tailwind en pratique

Liste complète des sujets

  • Structure d’un document HTML et métadonnées
  • HTML sémantique : header, nav, main, section, article et footer
  • Formulaires, champs, libellés et validation native
  • Tableaux, images responsives et médias
  • Sélecteurs, cascade, héritage et spécificité
  • Modèle de boîte, box-sizing et unités (px, rem, em, %, vw/vh)
  • Positionnement : static, relative, absolute, fixed et sticky
  • Flexbox : axes, alignement et distribution
  • CSS Grid : lignes, colonnes, zones et grille implicite
  • Variables CSS et organisation des styles
  • Responsive : mobile first, media queries et container queries
  • Transitions, animations et transformations
  • Tailwind CSS : utilitaires, configuration et composants
