Cours

Infrastructure as Code

Arrêtez de configurer les serveurs à la main : décrivez l’infrastructure dans des fichiers versionnés — puis testez cette description, analysez-la, et faites-la passer par une chaîne.

  • 80 heures
  • Niveau: intermédiaire

Ce qu’il vous faut d’abord

Exige le cloud et un compte chez un fournisseur — le cours provisionne de la vraie infrastructure.

Ce que vous allez apprendre

  • Provisionnement déclaratif avec Terraform, et le HCL dans lequel il s’écrit
  • L’état : le fichier, le backend distant, le verrouillage et son découpage
  • Modules réutilisables, workspaces et environnements multiples
  • Tester le code d’infrastructure, et analyser ce qu’il expose
  • Terraform dans la chaîne, et à quoi sert la revue d’un plan
  • Gestion de configuration avec Ansible (et aperçu de Chef, Puppet, Salt)
  • Infrastructure éphémère et reproductible — et ce qu’elle coûte

Liste complète des sujets

  • Provisionnement et gestion de configuration : deux métiers différents
  • Terraform : providers, resources, variables et outputs
  • HCL : expressions, locals, contraintes de type et règles de validation
  • count, for_each, et les méta-arguments qui façonnent une ressource
  • Data sources : lire une infrastructure que vous n’avez pas créée
  • Le cycle de vie d’une ressource : replace, ignore_changes et depends_on
  • L’état Terraform : le fichier d’état, le backend distant et le verrouillage
  • Découper l’état, et importer une infrastructure qui existe déjà
  • Plan et apply : relire le changement avant de l’appliquer
  • Modules réutilisables, le registry, et versionner ce que vous publiez
  • Workspaces, environnements multiples, et la place de Terragrunt
  • Secrets et valeurs sensibles : ce qui ne doit jamais atteindre le fichier d’état
  • Tester les modules : validate, tests unitaires et une exécution de bout en bout
  • Analyser ce que le code expose : Checkov, Trivy, tfsec et Terrascan
  • Terraform dans la chaîne : GitHub Actions, GitLab CI et un plan relu
  • Le coût avant la facture : Infracost, et la ressource que personne n’assume
  • Aperçu de Pulumi, CloudFormation, AWS CDK et OpenTofu
  • Ansible : inventaire, playbooks, rôles et idempotence
  • Aperçu de Chef, Puppet et Salt
  • Images machine avec Packer, et infrastructure immuable et reproductible
