Cours

Automatisation des API et du Mobile

Tester là où le défaut coûte le moins cher à trouver : à l’API, avant l’écran — et dans l’application, là où est l’utilisateur.

  • 60 heures
  • Niveau: intermédiaire

Ce qu’il vous faut d’abord

Exige des notions de programmation. Ne dépend pas du cours d’automatisation web — les deux peuvent être suivis dans n’importe quel ordre.

Ce que vous allez apprendre

  • HTTP, REST et contrat d’API pour les testeurs
  • Postman et Newman : de la collection manuelle à l’exécution dans la chaîne
  • REST Assured et Karate : tests d’API en code
  • Contrat, schéma et tests d’intégration entre services
  • Automatisation mobile : Appium, Espresso et Detox
  • Émulateur, appareil réel et parc d’appareils dans le cloud

Liste complète des sujets

  • HTTP pour les testeurs : méthodes, codes de statut et en-têtes
  • REST, JSON et le contrat que l’API promet de tenir
  • Authentification d’API : clé, jeton, JWT et OAuth
  • Postman : requêtes, variables, environnements et collections
  • Tests et assertions dans Postman
  • Newman : lancer la collection en ligne de commande et dans la chaîne
  • REST Assured : test d’API en Java avec une syntaxe fluide
  • Karate : scénarios en Gherkin sans écrire de code de liaison
  • Panorama de SoapUI et des services SOAP historiques
  • Validation de schéma JSON et test de contrat
  • Services simulés (mock server) et virtualisation de service
  • Test d’intégration entre services et le problème de l’ordre
  • Idempotence, reprise et test délibéré du cas d’erreur
  • Automatisation mobile : ce qui change par rapport au web
  • Appium : un pilote pour Android et iOS
  • Espresso : test natif Android
  • Detox : test d’application React Native
  • Panorama de SwiftTesting et XCUITest sur iOS
  • Émulateur, simulateur et appareil réel : quand chacun ment
  • Parc d’appareils dans le cloud et matrice de compatibilité
  • Gestes, permissions et états de l’application dans les tests
  • Tester l’application hors ligne et avec un réseau dégradé
