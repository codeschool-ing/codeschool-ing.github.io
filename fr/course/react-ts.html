Front-end avec React et TypeScript

Ce que réclament la plupart des offres d’emploi : composants, état typé, le modèle de rendu qui les porte, et la réponse full-stack que React a gagnée avec Next.js.

  • Niveau: intermédiaire

Ce qu’il vous faut d’abord

Les deux sont nécessaires.

Ce que vous allez apprendre

  • Composants, props et le modèle de rendu : ce qui se re-rend, et pourquoi
  • État et effets : les hooks, leurs règles, et le tableau de dépendances
  • La donnée à l’écran : React Query, formulaires, Suspense et error boundaries

  • Listes, clés et rendu conditionnel

  • Suspense, chargement paresseux et découpage du code

  • Server Components et la frontière client

  • Performance : memo, le profiler, et le re-rendu que personne n’a demandé
  • Tests avec Vitest et React Testing Library
