Python para Ciencia de Datos: NumPy, pandas y Notebooks

La pila científica en la mano: arrays que no necesitan bucle, DataFrames que aguantan un conjunto de datos real y un notebook que otra persona puede ejecutar.

  • 70 horas
  • Nivel: intermedio

Lo que necesitas antes

Requiere Python — el lenguaje, no las bibliotecas. La estadística ayuda y no se da por supuesta: aquí los gráficos se dibujan antes de interpretarse.

Lo que vas a aprender

  • Jupyter, y un notebook que se ejecuta de arriba abajo
  • NumPy: arrays, vectorización y broadcasting
  • pandas: Series, DataFrame, selección y tipos
  • Agrupar, unir y remodelar datos
  • Gráficos con matplotlib y seaborn
  • Reproducibilidad: entornos, semillas y datos que no se mueven
