Course

Swift

Apple’s language, from the syntax to the parts that shape every iOS app: optionals, value semantics, protocols, and the concurrency that arrived with async/await.

  • 80 hours
  • Level: beginner

What you need first

No previous Swift. A Mac is needed for the platform work in the next course; the language itself compiles anywhere.

What you will learn

  • Syntax, types, optionals, and a compiler that insists
  • Structs and classes: value and reference semantics
  • Protocols, generics and protocol-oriented design
  • Errors, Result, and failure that was expected
  • Concurrency: async/await, tasks and actors
  • Testing, packages and the Swift toolchain

Full topic list

  • let, var, type inference, and strong typing that shows up early
  • Optionals: if let, guard let, and the force unwrap that crashes
  • Functions, argument labels, closures and trailing closure syntax
  • Collections, map/filter/reduce, and lazy sequences
  • Structs against classes: value and reference semantics in practice
  • Properties: stored, computed, observed and lazy
  • Enums with associated values, and pattern matching
  • Protocols, extensions and default implementations
  • Generics, associated types and opaque return types
  • Protocol-oriented programming: composition instead of inheritance
  • Memory: ARC, strong, weak, unowned, and the retain cycle
  • Errors: throws, do/catch, Result and rethrows
  • Codable: JSON in and out, with the compiler doing the work
  • Concurrency: async/await, Task and cancellation
  • Actors, Sendable, and the data race the compiler can catch
  • Property wrappers and result builders, from the outside in
  • Access control, modules and namespaces
  • Testing with XCTest and Swift Testing
  • Swift Package Manager, dependencies and the toolchain
  • Where Swift runs besides the iPhone: macOS, server and Linux
