Security that runs on every commit: scanning in the pipeline, hardened images, dependencies under control and policy as code.

What you will learn

Full topic list

  • DevSecOps and DevOps: what actually changes in the routine
  • Shifting security left without stalling delivery
  • Static analysis (SAST): configuring, tuning and living with false positives
  • Dynamic analysis (DAST) in a staging environment
  • Composition analysis (SCA) and vulnerabilities in dependencies
  • Secret scanning in the repository and in the Git history
  • Quality gates: when to break the build and when to just warn
  • Container image scanning and minimal base images
  • Safe execution: unprivileged user, read-only filesystem and capabilities
  • Kubernetes: security context, admission policies and limits
  • Scanning tools: Nessus, OpenVAS, Qualys and Trivy
  • The software supply chain: where it breaks
  • SBOM: generating, storing and querying it (CycloneDX and SPDX)
  • Artefact signing, verification and provenance (SLSA and Sigstore)
  • Dependency risk: update, pin or replace
  • Hardening the pipeline: runner permissions, isolation and trusted actions
  • Secrets in the pipeline: vaults, federated identity and minimal scope
  • Automated remediation and bot-driven dependency updates
  • Policy as code: OPA, Conftest and infrastructure checks
  • Metrics: time to fix, scan coverage and security debt
