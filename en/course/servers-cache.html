Web Servers and Caching

Get the application online and make it answer fast under load.

  • 50 hours
  • Level: intermediate

What you need first

Requires the Linux command line. An application of your own to put behind the server helps, but is not assumed.

What you will learn

  • Servers and reverse proxies: Nginx, Apache, Caddy
  • Certificates, SSL/TLS and server security
  • HTTP caching: headers, validation and invalidation
  • Server-side caching with Redis and Memcached
  • Caching strategies and common traps

Full topic list

  • Web servers: Nginx, Apache and Caddy
  • Reverse proxy, load balancing and serving static files
  • TLS certificates, free issuance and automatic renewal
  • Security headers and server hardening
  • HTTP caching: Cache-Control, ETag and conditional validation
  • Cache invalidation and the problem of stale data
  • CDN: edge, origin and content purging
  • Redis: data structures, expiry and persistence
  • Memcached and how it compares with Redis
  • Caching patterns: cache-aside, write-through and write-behind
  • Cache stampede and warming
