Back-end with Go

The server in Go: HTTP with the standard library, gRPC, databases and real time — from the first endpoint to the shipped binary.

  • 70 hours
  • Level: intermediate

What you need first

Requires the language and concurrency: this course starts at the server.

What you will learn

  • HTTP server with net/http and routing
  • Frameworks: when to use Gin, Echo, Fiber or none at all
  • Database access with pgx, GORM and migrations
  • gRPC and Protocol Buffers for internal services
  • Structured logging and real-time communication
  • Deployment: a single binary in a minimal container

Full topic list

  • HTTP server with net/http: handlers, mux and the 1.22 routing
  • Middleware: logging, panic recovery, CORS and authentication
  • JSON in and out, validation and standardised errors
  • A look at the frameworks: Gin, Echo, Fiber and Beego
  • When the standard library is enough and the framework gets in the way
  • Database access with database/sql and pgx
  • ORM with GORM: mapping, relationships and pitfalls
  • sqlc: SQL that becomes typed Go code
  • Migrations, transactions and connection pooling
  • gRPC and Protocol Buffers: contract, code generation and streaming
  • When gRPC beats REST and when it does not
  • Structured logging with slog, zerolog and zap
  • Real-time communication: WebSocket, Melody and Centrifugo
  • Per-environment configuration, flags and variables
  • Handler tests with httptest and integration tests
  • Cross-compilation and a single binary in a distroless container
  • Health checks, metrics and graceful shutdown
