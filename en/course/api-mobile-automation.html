Course

API and Mobile Automation

Testing where the defect is cheapest to find: at the API, before the screen — and in the app, where the user is.

  • 60 hours
  • Level: intermediate

What you need first

Requires some programming knowledge. It does not depend on the web automation course — the two can be taken in any order.

What you will learn

  • HTTP, REST and the API contract for testers
  • Postman and Newman: from a manual collection to running in the pipeline
  • REST Assured and Karate: API testing in code
  • Contract, schema and integration testing between services
  • Mobile automation: Appium, Espresso and Detox
  • Emulator, real device and device cloud

Full topic list

  • HTTP for testers: methods, status codes and headers
  • REST, JSON and the contract the API promises to honour
  • API authentication: key, token, JWT and OAuth
  • Postman: requests, variables, environments and collections
  • Tests and assertions inside Postman
  • Newman: running the collection on the command line and in the pipeline
  • REST Assured: API testing in Java with a fluent syntax
  • Karate: Gherkin scenarios without writing glue code
  • An overview of SoapUI and legacy SOAP services
  • JSON schema validation and contract testing
  • Mock servers and service virtualisation
  • Integration testing between services and the ordering problem
  • Idempotency, retries and deliberately testing the error path
  • Mobile automation: what differs from the web
  • Appium: one driver for Android and iOS
  • Espresso: native Android testing
  • Detox: testing a React Native app
  • An overview of SwiftTesting and XCUITest on iOS
  • Emulator, simulator and real device: when each one lies
  • Device clouds and the compatibility matrix
  • Gestures, permissions and app states in tests
  • Testing an app offline and on a poor connection
