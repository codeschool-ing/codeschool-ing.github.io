Course

Kotlin

The language Android runs on, learned properly: null safety that removes a whole class of crash, coroutines instead of callbacks, and a standard library that shortens every second line.

  • 80 hours
  • Level: beginner

What you need first

No previous Kotlin. Programming in any language helps: the course moves quickly through the syntax that will already look familiar.

What you will learn

  • Syntax, types, and a compiler that will not let null through
  • Functions, lambdas and the collections library
  • Classes, data classes, sealed classes and objects
  • Coroutines: suspending functions, scopes and structured concurrency
  • Flow, for values that arrive over time
  • Testing, modules, and Kotlin outside Android

Full topic list

  • val, var, and type inference
  • Nullable types: the safe call, the elvis operator, and the !! nobody should write
  • Functions: default arguments, named arguments and single-expression bodies
  • Lambdas, higher-order functions and the trailing lambda
  • Collections: map, filter, fold, and the sequence that is lazy
  • Scope functions: let, run, with, apply and also
  • Classes, constructors, properties and init blocks
  • Data classes, destructuring and copy
  • Sealed classes, and when expressions the compiler forces you to finish
  • Objects, companion objects and singletons
  • Interfaces, delegation and extension functions
  • Generics, variance and reified type parameters
  • Exceptions, Result, and handling failure without throwing
  • Coroutines: suspend, launch, async and the dispatcher
  • Structured concurrency: scope, job and cancellation
  • Flow: cold streams, operators and collection
  • StateFlow and SharedFlow for state that is observed
  • Testing with JUnit, kotlin.test and the coroutine test utilities
  • Gradle, modules and the Kotlin toolchain
  • Kotlin beyond Android: server, multiplatform and scripting
