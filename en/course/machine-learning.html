Machine Learning: Models, Evaluation and Deployment

Training a model is the easy part. This is the split that does not leak, the metric that matches the decision, the feature that came from the business — and the model going out behind an endpoint.

  • 90 hours
  • Level: intermediate

What you need first

Requires the scientific stack in Python and statistics — inference, not just averages. The engineering around a model in production, with feature stores and retraining, is Data Engineering’s ml-mlops.

What you will learn

  • Framing: what the model decides, and what being wrong costs
  • Supervised learning: regression, classification and their metrics
  • Trees and ensembles: the model that usually wins in practice
  • Feature engineering, pipelines and leakage
  • Unsupervised learning: clustering and dimensionality reduction
  • From notebook to service: a model other people can call

Full topic list

  • Framing the problem: prediction, decision, and the cost of each kind of error
  • The baseline: the trivial rule the model has to beat
  • Train, validation and test; cross-validation, and the split that respects time
  • Data leakage: the ways it gets in, and how it looks in the metrics
  • Linear and logistic regression: regularisation and reading the coefficients
  • k-nearest neighbours, naive Bayes and support vector machines
  • Decision trees: depth, purity, and reading one out loud
  • Random forests, gradient boosting, XGBoost and LightGBM
  • Hyperparameters: grid, random and Bayesian search
  • Classification metrics: accuracy, precision, recall, F1 and ROC AUC
  • The threshold is a business decision, not the default 0.5
  • Regression metrics: MAE, RMSE, MAPE and R²
  • Imbalanced classes: resampling, class weights, and what the metric is hiding
  • Feature engineering: encoding, scaling, dates and text
  • scikit-learn pipelines: transformers, column selection and reproducibility
  • Clustering: k-means, DBSCAN and hierarchical — and how to read the result
  • Dimensionality reduction: PCA, t-SNE and UMAP
  • Recommendation: collaborative filtering and the cold start
  • Interpretability: coefficients, feature importance, SHAP and partial dependence
  • Bias and fairness: the protected attribute you left out and the proxy you kept
  • Serialising a model and serving it behind an API
  • Batch scoring, monitoring, and the drift that arrives without an announcement
