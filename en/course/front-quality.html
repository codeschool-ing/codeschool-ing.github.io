Course

Testing, Security and Accessibility

What separates a site that works from a product people can trust.

  • 60 hours
  • Level: intermediate

What you need first

Requires an application of your own to test, in any of the four frameworks. The course brings the tests, not the app.

What you will learn

  • Unit and component tests (Vitest, Jest)
  • End-to-end tests (Playwright, Cypress)
  • Authentication strategies: sessions, JWT, OAuth
  • Web security: CORS, HTTPS, CSP and OWASP risks
  • Accessibility: WCAG, keyboard, screen readers and contrast

Full topic list

  • The testing pyramid applied to the front-end
  • Unit and component tests with Vitest and Jest
  • Testing Library: test the way the user uses it
  • End-to-end tests with Playwright and Cypress
  • Authentication: cookie session, JWT, OAuth and OpenID
  • Storing tokens safely in the browser
  • CORS: what it is, when it breaks and how to fix it
  • HTTPS, Content Security Policy (CSP) and security headers
  • OWASP Top 10 on the front-end: XSS, CSRF and clickjacking
  • Accessibility: WCAG and levels A, AA and AAA
  • Keyboard navigation, visible focus and tab order
  • ARIA, screen readers and alternative text
  • Contrast, target size and respecting reduced motion
