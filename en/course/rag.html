RAG and Context Engineering

Make the model answer about what it has never seen: your company’s documents, with the source cited.

  • 70 hours
  • Level: intermediate

What you need first

Requires embeddings and a vector database — RAG is what gets built on top of them.

What you will learn

  • What RAG is and when it beats fine-tuning
  • The full pipeline: chunk, index, retrieve and generate
  • Frameworks: LangChain, LlamaIndex, Haystack and RAGFlow
  • Context engineering: external memory and dynamic filters
  • Context compaction and isolation

  • Use cases: documentation, support, legal and internal knowledge bases

  • Chunking: size, overlap and semantic boundaries
  • Generating and storing the chunk embeddings
  • The retrieval process: search, reranking and filters
  • Generating from the retrieved sources and citing them
  • Measuring the quality of retrieval and of the final answer
  • Implementing directly with the provider SDK
  • LangChain and LlamaIndex
  • Haystack and RAGFlow
  • Context engineering: filling the window with only what matters
  • External memory: history, profile and conversation state
  • Dynamic filters by user, permission and data scope
  • Context compaction: summarising without losing the essentials
  • Context isolation: separating tasks and avoiding contamination
  • Cost per query and retrieval caching
