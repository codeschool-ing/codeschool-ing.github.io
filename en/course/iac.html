Course

Infrastructure as Code

Stop configuring servers by hand: describe the infrastructure in version-controlled files — then test that description, scan it, and put it through a pipeline.

  • 80 hours
  • Level: intermediate

What you need first

Requires cloud and an account with a provider — the course provisions real infrastructure.

What you will learn

  • Declarative provisioning with Terraform, and the HCL it is written in
  • State: the file, the remote backend, locking and splitting it
  • Reusable modules, workspaces and multiple environments
  • Testing infrastructure code, and scanning it for what it exposes
  • Terraform inside the pipeline, and what a plan review is for
  • Configuration management with Ansible (and an overview of Chef, Puppet, Salt)
  • Ephemeral, reproducible infrastructure — and what it costs

Full topic list

  • Provisioning and configuration management: two different jobs
  • Terraform: providers, resources, variables and outputs
  • HCL: expressions, locals, type constraints and validation rules
  • count, for_each, and the meta-arguments that shape a resource
  • Data sources: reading infrastructure you did not create
  • The resource lifecycle: replace, ignore_changes and depends_on
  • Terraform state: the state file, remote backend and locking
  • Splitting state, and importing infrastructure that already exists
  • Plan and apply: reviewing the change before applying it
  • Reusable modules, the registry, and versioning what you publish
  • Workspaces, multiple environments, and where Terragrunt fits
  • Secrets and sensitive values: what must never reach the state file
  • Testing modules: validate, unit tests and an end-to-end run
  • Scanning what the code exposes: Checkov, Trivy, tfsec and Terrascan
  • Terraform in the pipeline: GitHub Actions, GitLab CI and a reviewed plan
  • Cost before the bill: Infracost, and the resource nobody owns
  • An overview of Pulumi, CloudFormation, AWS CDK and OpenTofu
  • Ansible: inventory, playbooks, roles and idempotency
  • An overview of Chef, Puppet and Salt
  • Machine images with Packer, and immutable, reproducible infrastructure
