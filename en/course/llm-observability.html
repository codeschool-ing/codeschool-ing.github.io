Course

LLM Observability and Evaluation in Production

"It worked in the demo" is not "it worked": instrument it, evaluate it and regression-test every change.

  • 50 hours
  • Level: advanced

What you need first

Requires an agent or a RAG application already running — there is nothing to instrument before that.

What you will learn

  • Tracing and logging model calls
  • Monitoring cost, latency and quality in production
  • Tools: LangSmith, Langfuse, Helicone and Arize AI
  • Evaluation types: deterministic, model-based and human
  • Evaluation metrics and tools (DeepEval, RAGAS)
  • Regression testing on every prompt or model change

Full topic list

  • Tracing a single call and a chain of calls
  • Logging inputs and outputs without leaking personal data
  • Monitoring cost per request, per user and per feature
  • Monitoring latency, time to first token and failures
  • Monitoring in production: volume, errors and satisfaction signals
  • LangSmith and Langfuse
  • Helicone and Arize AI
  • Deterministic evaluation: exact match, format and rules
  • Scoring live traffic: sampling what to grade, and the cost of grading it
  • Human evaluation: rubrics, sampling and inter-rater agreement
  • Metrics: precision, recall, faithfulness and relevance
  • DeepEval and RAGAS
  • Evaluation sets: building, versioning and maintaining them
  • Regression testing when changing prompt, model or version
  • Wiring evaluation into the continuous integration pipeline
  • Dashboards and alerts for quality drops
