Prompt Engineering

Chatting with a model is easy; getting the right answer every time is a craft. Design, configure and genuinely test your prompts.

  • 60 hours
  • Level: beginner

What you need first

Everyday computer and internet use.

What you will learn

  • How a language model works and what a prompt is
  • Terminology: tokens, context, hallucination, RAG and agents
  • Sampling parameters: temperature, top-k and top-p
  • Output control: token limits, stop sequences and penalties
  • Structured output in JSON, XML and Markdown
  • Techniques: zero-shot, few-shot, chain of thought, ToT, ReAct
  • Automatic prompt generation using the model itself
