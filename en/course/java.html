Course

Java

The most widely employed language in the corporate world: strong typing, object orientation done properly and thirty years of compatibility.

  • 80 hours
  • Level: beginner

What you need first

None. This course teaches the language from scratch — it is the entry point for anyone who has never written Java.

What you will learn

  • The JVM, the life of a program and the syntax of the language
  • Types, casting, strings, arrays and control flow
  • Full object orientation: classes, inheritance, interfaces and encapsulation
  • Records, enums, nested classes and packages
  • Collections and generics: picking the right structure
  • Exceptions, annotations and the module system
