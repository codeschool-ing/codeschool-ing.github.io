Excel for Data Analysis

The tool every company already has — used properly: pivot tables, Power Query and the data model.

  • 60 hours
  • Level: beginner

What you need first

No programming required. Basic Excel is assumed; the pivot table is not.

What you will learn

  • Formulas that solve real problems
  • Lookup and reference functions
  • Tables, validation and conditional formatting
  • Pivot tables and slicers
  • Power Query: importing, cleaning and combining
  • Power Pivot, measures and dashboards in Excel

  • Conditional aggregation: SUMIFS, COUNTIFS and AVERAGEIFS
  • Text and date functions for cleaning
  • Excel tables: ranges that grow on their own
  • Data validation and drop-down lists
  • Conditional formatting that communicates
  • Pivot tables: fields, values, filters and grouping
  • Calculated fields and items, slicers and timelines
  • Excel charts and sparklines
  • Power Query: importing from files, databases and the web
  • Power Query: transform, merge, append and unpivot
  • Power Pivot: the data model and relationships
  • DAX measures: counts, sums and period comparisons
  • Building a navigable dashboard in Excel
  • The limits of Excel and when to move to a database or BI platform
