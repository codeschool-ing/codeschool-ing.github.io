Linux and the Command Line

The system that runs the internet: master the terminal and stop depending on a graphical interface.

  • 70 hours
  • Level: beginner

What you need first

No programming required. It is the base of every infrastructure, data and security track.

What you will learn

  • Operating systems: Linux, Unix and Windows in operations
  • Distributions: Ubuntu/Debian, RHEL and derivatives, SUSE
  • Terminal: navigation, permissions, users and processes
  • Scripting with Bash (and an overview of PowerShell)
  • Text processing: grep, sed, awk and pipes
  • Process and performance monitoring from the command line
  • Terminal editors: Vim, Nano, Emacs

Full topic list

  • Linux, Unix and Windows: differences in day-to-day operations
  • Distributions: Ubuntu/Debian, RHEL, Rocky, Alma and SUSE
  • The filesystem, absolute and relative paths
  • Permissions, owners, groups, sudo and umask
  • Users, services and systemd
  • Processes: ps, top, htop, kill, jobs and signals
  • Package managers: apt, dnf/yum and zypper
  • Text: grep, sed, awk, cut, sort, uniq, pipes and redirection
  • Bash scripting: variables, conditionals, loops and functions
  • An overview of PowerShell for Windows environments
  • Performance: CPU, memory, disk and I/O
  • Terminal editors: Vim, Nano and Emacs
  • Scheduling tasks: cron and systemd timers
