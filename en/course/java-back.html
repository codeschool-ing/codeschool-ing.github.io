Course

Back-end with Java and Spring

The ecosystem behind banking, industry and government: Spring Boot, persistence and the most mature toolchain on the market.

  • 70 hours
  • Level: intermediate

What you need first

Requires the language and its standard library: this course starts at the ecosystem.

What you will learn

  • Maven and Gradle: dependencies, build and project layout
  • Spring Boot: autoconfiguration, dependency injection and profiles
  • Spring MVC: controllers, DTOs and validation
  • Persistence: JDBC, Hibernate and Spring Data JPA
  • Spring Security, structured logging and documentation
  • Layered testing and shipping the artefact

Full topic list

  • Maven: dependencies, build lifecycle, plugins and repository
  • Gradle: build script, tasks and incremental builds
  • A look at Bazel and where it shows up
  • Spring Boot: autoconfiguration, starters and per-environment profiles
  • Dependency injection and inversion of control in practice
  • Spring MVC: controllers, DTOs and validation (Bean Validation)
  • Global error handling and standardised responses
  • A look at web frameworks: Quarkus, Javalin, Play and Micronaut
  • JDBC: the foundation everything else sits on
  • Hibernate and JPA: object-relational mapping and the N+1 problem
  • Spring Data JPA: entities, relationships, queries and projections
  • A look at EBean and lightweight alternatives
  • Flyway or Liquibase for database migration
  • Transactions, isolation and connection pooling
  • Spring Security: authentication, authorisation and JWT
  • Structured logging: SLF4J as the facade, Logback, Log4j2 and TinyLog
  • Javadoc and API documentation with OpenAPI
  • Unit testing with JUnit 5 and TestNG
  • Test doubles with Mockito and integration tests with Testcontainers
  • API testing with REST Assured and load testing with JMeter
  • Behaviour testing with Cucumber-JVM
  • Actuator, metrics and health checks
  • Packaging as a jar, a container image and shipping it
