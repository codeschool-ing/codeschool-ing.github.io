iOS Apps with SwiftUI

A real iPhone app: SwiftUI, state the framework watches, data from the network and from SwiftData, and an archive that gets through App Store review.

  • 90 hours
  • Level: intermediate

What you need first

Requires Swift, async/await included. A Mac with Xcode is required — the platform does not build anywhere else.

What you will learn

  • SwiftUI: views, state and the layout system
  • Data flow: State, Binding, Observable and the environment
  • Networking with URLSession, persistence with SwiftData
  • Navigation, lists and the screens a real app has
  • Background, notifications and permissions
  • Signing, TestFlight and App Store review

Full topic list

  • The Xcode project: targets, schemes, bundle id and Info.plist
  • The SwiftUI app lifecycle: App, Scene and the view hierarchy
  • Views as values, and a body that runs again
  • Layout: stacks, frames, alignment, spacers and GeometryReader
  • Modifiers: the order matters, and the ones that only look alike
  • State and Binding: one source of truth
  • Observable, environment objects, and passing state down the tree
  • Lists, ForEach, identity and performance
  • NavigationStack: paths, sheets and full-screen covers
  • Forms, text fields, focus and the keyboard
  • Animation, transitions and matched geometry
  • URLSession with async/await: decoding, and the error state
  • SwiftData: models, queries, relationships and migration
  • The repository between the network and the store
  • Images: AsyncImage, caching and memory
  • Background tasks and refresh: what iOS actually allows
  • Notifications: local, remote, the permission and the delegate
  • Privacy strings and permissions: camera, location, photos and tracking
  • Accessibility: labels, traits, Dynamic Type and VoiceOver
  • Testing: unit tests, UI tests, and previews as a working tool
  • Signing: certificates, provisioning profiles and the archive
  • TestFlight, App Store Connect, and the review that rejects you
