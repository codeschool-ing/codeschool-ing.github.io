Cloud and Serverless

Where infrastructure lives today: providers, managed services and computing without servers.

  • 60 hours
  • Level: intermediate

What you need first

Requires networks: a VPC is a network, and IAM only makes sense once you have one.

What you will learn

  • Cloud models: IaaS, PaaS, SaaS
  • An overview of providers: AWS, Azure, Google Cloud and the alternatives
  • Compute, storage, networking and identity in the cloud
  • Serverless: AWS Lambda, Cloudflare Workers, Vercel, Netlify
  • Costs: how to estimate them, measure them and avoid surprises

Full topic list

  • IaaS, PaaS and SaaS: what each model delivers and what is left to you
  • Public, private and hybrid cloud
  • Providers: AWS, Azure, Google Cloud, DigitalOcean, Hetzner and Linode
  • Compute: virtual machines, images and autoscaling
  • Storage: object, block and file systems
  • Cloud networking: VPC, subnets, security groups and load balancers
  • Identity and access (IAM): users, roles and policies
  • Serverless: AWS Lambda, Cloudflare Workers, Vercel and Netlify
  • Regions, availability zones and their effect on latency
  • Costs: billing models, budgets and spend alerts
