Docker and Containers

Package your application once and run it anywhere — from a colleague’s laptop to the production server.

  • 50 hours
  • Level: intermediate

What you need first

Requires the Linux command line. No specific programming language required.

What you will learn

  • What a container is and why it replaced the virtual machine
  • Images, layers and a Dockerfile that builds efficiently
  • Volumes, bind mounts and data persistence
  • Networking, Docker Compose and a complete development environment
  • Registries, image versioning and security
  • A look at deployment: Swarm, Nomad, Kubernetes and PaaS
