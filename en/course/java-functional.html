Course

Java: Functional and Concurrent

The Java that changed: lambdas, streams, virtual threads and the standard library you use every day.

  • 70 hours
  • Level: intermediate

What you need first

Requires the Java course: object orientation, collections and exceptions are assumed here.

What you will learn

  • Lambdas, functional interfaces and composition
  • Stream API: transforming a collection without a loop
  • `Optional` and the end of the careless `NullPointerException`
  • Concurrency: threads, executors and virtual threads
  • Memory model, `volatile` and synchronisation
  • Standard library: files, date and time, networking, regular expressions and cryptography

Full topic list

  • Lambda expressions: syntax, capture and what they replace
  • Functional interfaces: `Function`, `Predicate`, `Supplier` and `Consumer`
  • Method and constructor references
  • Higher-order functions: taking and returning behaviour
  • Function composition: `andThen`, `compose` and chaining
  • Stream API: source, intermediate and terminal operations
  • `map`, `filter`, `reduce` and collectors
  • `Collectors`: grouping, partitioning and joining
  • Parallel streams: when they help and when they get in the way
  • `Optional`: creating, chaining and the `get()` antipattern
  • Threads: creating, starting and what one really costs
  • The Java memory model: visibility and reordering
  • The `volatile` keyword: what it guarantees and what it does not
  • Synchronisation: `synchronized`, `Lock` and race conditions
  • Concurrent collections and atomics
  • Executors, thread pools and `CompletableFuture`
  • Virtual threads: what changes with Project Loom
  • Structured concurrency: an overview
  • Input and output: byte and character streams
  • Files and directories with NIO.2: `Path`, `Files` and walking a tree
  • Serialisation, JSON and the danger of unsafe deserialisation
  • Date and time: `LocalDate`, `Instant`, time zones and durations
  • Networking: sockets, `HttpClient` and HTTP calls in the standard library
  • Regular expressions: `Pattern`, `Matcher` and the cost of backtracking
  • Cryptography: digests, symmetric and asymmetric ciphers and `KeyStore`
  • Secure random generation and password storage
