Course

Manual Testing and Test Management

The part of the job no tool does: understanding the product, writing the case and proving the defect.

  • 60 hours
  • Level: beginner

What you need first

No programming required.

What you will learn

  • Test planning: scope, risk, environment and criteria
  • Cases and scenarios: writing what someone else can execute
  • Verification and validation, and compatibility testing
  • Functional techniques: regression, smoke, sanity, exploratory and UAT
  • An overview of non-functional techniques
  • Management: Jira, TestRail, Zephyr, reporting and test data

Full topic list

  • The test plan: scope, risk, resources, environment and schedule
  • Test cases and scenarios: precondition, step, expected result
  • Writing a case someone else can run without asking a single question
  • Case design techniques: equivalence partitioning and boundary values
  • Decision tables and state transition
  • Verification and validation: are we building it right, are we building the right thing
  • Compatibility testing: browser, operating system, device and resolution
  • Smoke testing: does the application even come up?
  • Sanity testing: did that specific fix work?
  • Regression testing: does what already worked still work?
  • Exploratory testing: a session with a charter and notes
  • User acceptance testing (UAT) and the client’s role
  • An overview of unit and integration testing and the use of mocks
  • A non-functional overview: load, performance, stress, security and accessibility
  • Reporting a defect: reproduction, severity, priority and evidence
  • The defect lifecycle and triage
  • Jira and Atlassian, Trello, YouTrack and Assembla
  • Case management: TestRail, qTest, TestLink and Zephyr
  • Reporting: Allure, jUnit and what leadership actually reads
  • Test data: generating it, anonymising it and reusing it
  • Test environments and the "it works on my machine" problem
  • Email testing: Mailinator, Gmail Tester and confirmation flows
