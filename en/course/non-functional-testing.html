Course

Non-functional Testing

The system does what it should — but does it hold up, is it accessible, and does it resist someone trying to break it on purpose?

  • 60 hours
  • Level: intermediate

What you need first

Requires web automation and a suite that already runs green.

What you will learn

  • Load, stress and performance: planning the test before running it
  • JMeter, K6, Gatling and Locust in practice
  • Front-end performance with Lighthouse and WebPageTest
  • Accessibility: WCAG, Wave, AXE and screen readers
  • Security testing: OWASP Top 10, attack vectors and scanning
  • Monitoring and watching for what testing does not catch

  • Front-end performance: Lighthouse, Core Web Vitals and WebPageTest
  • Performance budgets and performance regression in the pipeline
  • Accessibility: WCAG and levels A, AA and AAA
  • Wave, AXE and the browser accessibility audit
  • Keyboard navigation, visible focus and tab order
  • Screen readers: testing properly, not just passing the tool
  • Security testing: what QA does and where penetration testing begins
  • Authentication and authorisation: privilege escalation and sessions
  • Secret management: keys in the repository and in environment variables
  • The OWASP Top 10 applied to the test plan
  • Common attack vectors: injection, XSS, CSRF and malicious uploads
  • Vulnerability scanning and reading the report without panicking
  • Monitoring and logs: New Relic, Datadog, Grafana, Kibana and Sentry
