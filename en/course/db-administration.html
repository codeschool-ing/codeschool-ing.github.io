Database Server: Installation and Maintenance

Installing, configuring and keeping a database server alive — the work that begins where writing queries ends.

  • 70 hours
  • Level: intermediate

What you need first

Both are required: the language and the terminal. No programming language needed beyond SQL.

What you will learn

  • Installation, initial configuration and the parameters that actually matter
  • Memory, storage layout and the filesystem underneath
  • Roles, grants and least privilege inside the database itself
  • Routine maintenance: statistics, vacuum, bloat and reindexing
  • Upgrades and version migration without losing a weekend
  • PostgreSQL in depth, with MySQL, SQL Server and Oracle alongside
