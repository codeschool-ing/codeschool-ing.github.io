Android Apps with Jetpack Compose

A real Android app: a declarative interface in Compose, state that survives rotation, data from the network and from the database, and a build that reaches the Play Store.

  • 90 hours
  • Level: intermediate

What you need first

Requires Kotlin, coroutines and Flow included — the interface is built on them. The lifecycle it assumes is the one from mobile fundamentals.

What you will learn

  • Compose: composables, state and recomposition
  • Architecture: ViewModel, one-way data flow and injection
  • Data: Retrofit, Room, and the repository between them
  • Navigation, lists and the screens a real app has
  • Background work, notifications and permissions
  • Build, flavours, signing and the release to Play

Full topic list

  • The Android project: modules, manifest, Gradle and resources
  • Activities, the process, and where Compose fits in
  • Composables: functions that draw, and the ones that should not
  • State, remember, rememberSaveable, and the rotation that used to destroy everything
  • Recomposition: what triggers it, and how to avoid the wasteful kind
  • Layout in Compose: Column, Row, Box, constraints and modifiers
  • Material 3: theming, dark mode and dynamic colour
  • Lists with LazyColumn: keys, scrolling and pagination
  • Navigation Compose: routes, arguments and the back stack
  • ViewModel, UI state, and one-way data flow
  • Coroutines and Flow in the interface, aware of the lifecycle
  • Dependency injection with Hilt
  • Retrofit and OkHttp: calls, errors, retries and interceptors
  • JSON with kotlinx.serialization or Moshi
  • Room: entities, DAOs, migrations, and queries that return a Flow
  • The repository: one source of truth, cache and refresh
  • Images with Coil, and the memory a list of photos eats
  • WorkManager, for work that has to survive the app closing
  • Notifications, channels, and the permission Android 13 introduced
  • Runtime permissions, and the flow when the user says no twice
  • Testing: unit tests, Compose UI tests and screenshot tests
  • Build types, product flavours, signing, R8 and the app bundle
